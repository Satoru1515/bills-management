- 2026-10-08 00:30 · Fase 1 · domain/categorize.ts + tests · this commit · DEFAULT_CATEGORY_RULES holds the spec §5 table in order; createCategorizer(rules) compiles them once and returns the category of the first matching keyword, or Otros.
